## 📋 Quick Command Reference

### By Speed:
- **Fastest:** `--aggressive --concurrency 500` (15 sec)
- **Fast:** `--aggressive` (30 sec)
- **Normal:** (default) (2-5 min)
- **Slowest:** `--stealth` (30 min)

### By Coverage:
- **Minimal:** `-p 22,80,443` (3 ports)
- **Standard:** `-p 1-1024` (1024 ports)
- **Extended:** `-p 1-10000` (10k ports)
- **Full:** `-p 1-65535` (all ports)

### By Detection:
- **None:** (default, just port scan)
- **Specific:** `--asur-script http_title`
- **Multiple:** `--asur-script http_title,mysql_probe`
- **All:** `--asur-script all`

### By Focus:
- **Vulnerabilities:** `--asur-script cve_matcher`
- **Web Servers:** `--asur-script http_headers`
- **Databases:** `--asur-script mysql_probe,redis_probe`
- **Everything:** `--asur-script all`
